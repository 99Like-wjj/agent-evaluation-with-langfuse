技术核验补充

  • Trace与Observation概念：逻辑边界、上下文与后台导出。
  • Score数据模型：API/EVAL/ANNOTATION来源及可选comment字段。
  • Python SDK v5.1.0的DatasetClient：固定版本源码仍定义run_experiment，不与已删除的get/delete helper混淆。
  • W3C Trace Context与OTel Python传播：传播上下文和采样标志，通用示例应使用propagator。

本轮补充：输入边界与结果完整性

  • Observation 级评估器的取数范围：不自动读取同一 Trace 的子节点与兄弟节点。
  • 评估器迁移与映射：跨观测材料的组织，以及实验上下文的映射。
  • Python SDK v5.1.0 实验实现：异常项与最终 item_results 的关系。固定版本静态分析，不代表本文项目已经部署该版本。
  • 实验与 CI/CD：缺样本、重复 ID、执行失败和无效结果的处理。本文未引入自动发布门禁。
  • Masking：客户端脱敏钩子的作用范围，其他出口需分别处理。
  • 自托管 v3 到 v4：legacy、dual、events_only 模式与迁移步骤。
